## Details

**T10 Visibility, de-dupe, content facts.**
- **Visibility filter:** exclude `display:none`, `visibility:hidden`, zero-size, `aria-hidden="true"` subtrees, `inert`, `.slick-cloned`, `.swiper-slide-duplicate`, and elements fully off-canvas inside an `overflow:hidden` slider track. Each viewport is extracted separately, so a mobile-only menu counts only in `facts.mobile`.
- **De-dupe:** inside a page and viewport, drop a subtree whose normalized text and link set hash equals an earlier visible subtree.
- **Extractors:**
  - Links: raw `href` kept byte for byte, region, `isToggle`, `targetExists`.
  - Phone text: **`libphonenumber-js`** with default region US (D15). Excluded: matches inside licence-like tokens, ZIP codes, years and review counts.
  - Emails: `mailto:`, text, and `data-cfemail` decoded by XOR with the first byte. `[email protected]` is never kept.
  - Headings, hours blocks (text containing a day name and a time), JSON-LD, forms (visible fields only, no honeypots), images (bytes from response sizes), copyright years.
*Acceptance:* iphci yields `info@...` (anonymized) and each Plumbing/Heating/Cooling block once; hair-and-co yields its second-location team block once and one nav; the anonymized licence numbers in the jolly and arc labels (T5 keeps their prefixes, leading zeros and digit counts) produce no `phoneTexts`; casper's footer phone has `insideTelLink: false`.
