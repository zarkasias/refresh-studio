## Details

**T29 Projects and consent UI.** `/projects/new` (client name, site URL). Consent form: granted by, date, method (`email` | `signed`), evidence upload (email screenshot or PDF → Asset `document`), scope preview (origin computed from the URL, optional path prefix, max pages ≤ 25). The "Scan site" button is disabled without consent, and the server action calls `assertCrawlAllowed` before sending the event. A separate checkbox records "may also be kept as a test site" (D17). *Acceptance:* e2e: a project without consent cannot start a scan (UI and server action both refuse); axe has no serious or critical violations.
