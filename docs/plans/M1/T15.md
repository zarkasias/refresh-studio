## Details

**T15 Lighthouse runner.** **Lighthouse Node API**, mobile and desktop presets, run against the Chromium Playwright launched (`--remote-debugging-port`), through `guardedGoto` rules (robots, consent, cap; a Lighthouse run does not add a page). One run per page per preset (D9). The trimmed LHR is stored as an Asset; the summary goes into `AuditRun.lighthouse`. *Acceptance:* runs offline against the fixture server with throttling on. Unit tests compute the summary from a saved LHR JSON (the T34 real one once it exists, synthetic before that).
