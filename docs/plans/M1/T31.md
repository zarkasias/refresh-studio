## Details

**T31 Report renderer and share link.** One React renderer, two routes:
- `/r/[token]` (public, `noindex`, token hashed with `node:crypto` and compared, expired or revoked → plain "This link has expired" page, renders only the link-aware `resolveSharedReportVersion(link, history, now)`).
- `/print/reports/[versionId]` (worker-only, short-lived signed token, approved versions only, print CSS, page breaks).
Layout: business name, date, "Version n", what's working, five scores with plain labels, Fix now (sentence, why it matters, crop), Can wait, how we did this (pages scanned, tools used, consent note), next steps. Studio brand from `packages/brand`. *Acceptance:* e2e: an unapproved version is unreachable by both routes; axe has no serious or critical violations on `/r/[token]`; the report text passes the T22 jargon lint.
