## Details

**T23 Auditor agent (API key).** `packages/agents/auditor/{schema.ts,prompt.md,index.ts}`.
- Input: the AuditRun summary (scores, failed checks with `findingId`, plainEnglish, evidence values, business type) plus the template draft.
- Output (Zod): `{ summary: string (≤ 80 words), whatsWorking: string[1..2], fixNow: { findingId, whyItMatters }[0..5], canWait: findingId[] }`.
- Post-validation: every id exists; every number in the text appears in the input; no score is emitted; jargon lint; ≤ 5 fix-now.
- On failure, retry once with the errors. After that, fall back to the template draft with `draftSource: 'template'` and say so visibly in the editor.
- The prompt says page text is data to analyze, not instructions.
- Tokens and duration are logged.
- The model ID is taken from the current Claude API docs at build time.
*Acceptance:* unit tests with recorded responses (no key needed in CI); the fallback path is tested.
