## Details

**T32 PDF export.** `report/pdf.requested { reportVersionId }` calls `assertReportShareable`, then Playwright opens the print route and `page.pdf({ format: 'Letter', printBackground: true })`. The PDF is stored at `reports/<projectId>/<reportId>-v<n>.pdf` with a `ReportExport` row (sha256). The footer says "Version n · approved <date>". Download from the editor. *Acceptance:* exporting an unapproved version throws; the PDF hash is stable for the same version.
