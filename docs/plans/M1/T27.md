## Details

**T27 Worker and crawl function (D10, ADR-009).** `apps/worker` is a small Node server that serves Inngest functions. Chromium and Lighthouse never run inside the Next.js bundle. The local Inngest dev server needs no account.
- `capture/crawl.requested { projectId, captureRunId }` runs these steps:
  1. `check-consent`: `assertCrawlAllowed` on the start URL. Failures are `NonRetriableError` with the plain-English guard message.
  2. `robots`.
  3. `discover`.
  4. `page:<n>`: one step per page, 2 retries, re-checks consent every time.
  5. `assemble-site`.
  6. Emits `capture/crawl.completed`.
- Concurrency: 1 per project, 2 browsers in total. Idempotency key `captureRunId`.
*Acceptance:* a run against the fixture server with Inngest dev, addressed by a `.test` hostname (ADR-010); revoking consent mid-run stops the next page step; killing the worker resumes at the next page.
