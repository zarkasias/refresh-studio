# M1 section 7. ADR drafts (to commit as `accepted` after review)

Part of the [M1 plan](../M1.md).

- **007 — Site model v3: fonts and page builders.** Context: M1-notes Wix fonts; manifest builders on the slug branch. Decision: section 2a. Consequences: labels move to v3; one migration step; exporters read `family`; designer (M2) can use `raw` hints.
- **008 — Audit records and report approval.** Context: rule 2 (tool scores), rule 4 (approval), PRD "Consultant edits". Decision: section 2c. ReportVersion follows ADR-005 (frozen, newest only, numbered). Scores are copied from the AuditRun and checked by recomputation before approval. Dismissals are recorded and recompute deterministically. Share tokens are stored hashed. Generic versioning core shared with variants. Consequences: one more freeze trigger; the "Looks current" score is deterministic in M1.
- **009 — Jobs and runtime.** Context: Chromium and Lighthouse don't fit in a Next.js serverless bundle; rule 5/6 enforcement must be unavoidable. Decision: Inngest functions served by `apps/worker`; local-first (Inngest dev server on the consultant's machine) for M1; one guarded network path (`guardedFetch`/`guardedGoto`) enforced by lint; consent re-checked every page step; bot challenges stop the page and are never bypassed. Consequences: a hosted worker is a later decision (D10); the UA token is published.
- **010 — Fixtures without crawling (amends ADR-004).** Context: the consultant asked for synthetic HTML built from the labels; ADR-004 says "copy a pattern, never content". Decision: label-derived synthetic sites are allowed **only after anonymization** (T5); pattern fixtures need no label; fixture-only loopback URL schema, with production schemas staying strict (T8a); all tests run with external requests aborted; real captures only through `selectNetworkEligible`. Consequences: evals measure pattern handling, not real-world accuracy, until consenting prospects add real fixtures.
