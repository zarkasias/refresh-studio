## Details

**T4 Fixture server and network lockdown.** `evals/fixtures/server.ts` serves a directory on `127.0.0.1:<random port>`. `lockdownContext(context)` installs a Playwright route that **aborts every request whose host is not loopback**, and logs it. Fixture platform URLs such as `static.wixstatic.com/...` are fulfilled from local files by URL pattern, never fetched. `fixtureProject(port)` returns a Project with `consent.method: 'own-site'` scoped to the loopback origin, so `assertCrawlAllowed` still runs in tests. *Acceptance:* a test page that requests a real external URL produces an aborted request and zero sockets to non-loopback addresses (checked with a `net.connect` spy in Node).
